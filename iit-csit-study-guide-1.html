Explain the five generations of computers based on their key switching components, with examples.
▼

Five Generations of Computers:

1st Generation (1946-1956) - Vacuum Tubes

  • Switching Device: Vacuum Tubes
  • Size: Room-sized, very large
  • Speed: Slow (milliseconds)
  • Cost: Extremely expensive
  • Example: ENIAC, UNIVAC, Mark-I
  • Characteristics: Generated excessive heat, required cooling systems, high power consumption

2nd Generation (1956-1963) - Transistors

  • Switching Device: Transistors
  • Size: Cabinet-sized, smaller than vacuum tubes
  • Speed: Faster (microseconds)
  • Cost: Expensive but more affordable than generation 1
  • Example: IBM 7090, Honeywell 400
  • Characteristics: Less heat, lower power consumption, improved reliability

3rd Generation (1963-1971) - Integrated Circuits (ICs)

  • Switching Device: Integrated Circuits (Small Scale Integration)
  • Size: Desk-sized
  • Speed: Faster (nanoseconds)
  • Cost: Reduced cost
  • Example: IBM System/360, Honeywell 6000
  • Characteristics: Multiple transistors on single chip, parallel processing, introduction of operating systems

4th Generation (1971-1980) - Microprocessors

  • Switching Device: Microprocessors (Large Scale Integration - LSI, Very Large Scale Integration - VLSI)
  • Size: Personal Computer size
  • Speed: Much faster (picoseconds)
  • Cost: Affordable
  • Example: Apple II, IBM PC, Intel 4004, Intel 8085
  • Characteristics: Desktop computers, graphical user interfaces, networking capabilities

5th Generation (1980-Present) - AI and Advanced Processors

  • Switching Device: Ultra Large Scale Integration (ULSI), Quantum Computing
  • Size: Portable, smartphones, tablets, wearables
  • Speed: Extremely fast (femtoseconds)
  • Cost: Low cost, affordable
  • Example: Modern Intel/AMD processors, GPUs, AI chips
  • Characteristics: Artificial Intelligence, Quantum Computing, IoT, Cloud Computing, Mobile Computing
Define a computer system. Describe the internal functional units of a CPU (ALU, CU, and Registers).
▼

Definition of Computer System:

A computer system is an electronic device that accepts data as input, processes it using predefined instructions, and produces meaningful output. It consists of hardware (physical components) and software (programs and instructions) working together to perform computations and store information.

Internal Functional Units of CPU:

1. Arithmetic Logic Unit (ALU)

  • Performs all arithmetic operations (addition, subtraction, multiplication, division)
  • Performs all logical operations (AND, OR, NOT, XOR)
  • Compares values and sets condition flags
  • Most critical unit for actual data processing

2. Control Unit (CU)

  • Directs and coordinates all operations of the computer
  • Fetches instructions from memory
  • Decodes instructions and determines what to do
  • Controls the flow of data and instructions
  • Sends control signals to other units
  • Manages timing and synchronization

3. Registers

  • Extremely fast temporary storage locations within the CPU
  • Store data currently being processed
  • Store addresses of memory locations
  • Store instruction being executed
  • Much faster than main memory (RAM)
  • Limited in quantity (typically 8-32 registers)
  • Types: Accumulator Register, Data Registers, Address Registers, Instruction Register, Program Counter

What is Cache Memory? Explain why it is used despite its high cost.
▼

Cache Memory Definition:

Cache Memory is an extremely fast, small-sized memory that stores copies of frequently accessed data from main memory (RAM). It acts as a buffer between the CPU and main memory, reducing access time significantly.

Characteristics of Cache:

  • Very fast access time (1-10 nanoseconds)
  • Small storage capacity (256 KB - 16 MB per level)
  • Located directly on the CPU die or nearby
  • Expensive (10-100 times more expensive than RAM)
  • Automatically managed by hardware

Levels of Cache:

L1 Cache: Smallest but fastest (8-64 KB per core)

L2 Cache: Larger and slightly slower (256 KB - 1 MB)

L3 Cache: Largest but slower (2-20 MB, shared among cores)

Why Cache is Used Despite High Cost:

  • Speed: Cache is 100-1000x faster than main memory
  • Performance: Significantly improves CPU performance by reducing memory access time
  • Temporal Locality: Recently accessed data is likely to be accessed again
  • Spatial Locality: Data near accessed location is likely to be needed soon
  • Bottleneck Reduction: Eliminates memory access bottleneck
  • Small Size: Small quantity needed (KB-MB range)
  • ROI: Performance gain justifies the cost

What are different types of Read Only Memory (ROM)? Explain Mask ROM, PROM, EPROM, and EEPROM.
▼

Read Only Memory (ROM):

ROM is non-volatile memory that permanently stores data/firmware. Its contents are retained even when power is off. It is used to store the BIOS/firmware of a computer.

Types of ROM:

1. Mask ROM

  • The oldest type of ROM
  • Data is permanently written during the manufacturing process using a mask/template
  • Cannot be erased or reprogrammed after manufacture
  • Very cheap for large production runs
  • Used in: Game cartridges, calculator chips, embedded firmware

2. PROM (Programmable ROM)

  • Can be programmed once by the user after manufacture (using a PROM burner)
  • Once programmed, data cannot be changed or erased
  • Uses tiny fuses that are blown during programming
  • More flexible than Mask ROM for small production
  • Used in: Initial firmware loading, custom applications

3. EPROM (Erasable Programmable ROM)

  • Can be erased using ultraviolet (UV) light and reprogrammed
  • Has a transparent quartz window on top of the chip for UV exposure
  • Erasing takes 15–20 minutes under UV light
  • Can be reprogrammed multiple times
  • Used in: Development prototypes, older BIOS chips

4. EEPROM (Electrically Erasable Programmable ROM)

  • Can be erased and reprogrammed electrically (no UV light needed)
  • Can erase individual bytes instead of the whole chip
  • Much faster and more convenient than EPROM
  • Can be reprogrammed thousands of times
  • Used in: Modern BIOS/UEFI chips, smart cards, microcontrollers
  • Flash memory is a type of EEPROM widely used in USB drives, SSDs
Feature Mask ROM PROM EPROM EEPROM
Programmable No (factory only) Once Multiple (UV) Multiple (electrical)
Erasable No No Yes (UV light) Yes (electrically)
Cost Cheapest (bulk) Low Medium Highest
Flexibility None Low Medium High
What is an Instruction Set? Explain instruction format with example.
▼

Instruction Set:

An instruction set (also called Instruction Set Architecture or ISA) is the complete collection of all commands/instructions that a CPU can understand and execute. It acts as the interface between hardware and software.

Examples of Instructions:

  • ADD – Adds two values
  • MOV – Moves data from one location to another
  • LOAD – Loads data from memory to register
  • STORE – Stores data from register to memory
  • JMP – Jumps to a new instruction (branching)
  • SUB – Subtracts two values

Instruction Format:

An instruction format is the structure (layout) of a machine instruction. Every instruction typically contains:

  • Opcode (Operation Code): Specifies the operation to perform (e.g., ADD, MOV, LOAD). Typically 4–8 bits.
  • Operand(s): The data or address to operate on. Can be registers (R1, R2), memory addresses, or immediate values.

General Format:

| OPCODE  |  OPERAND 1  |  OPERAND 2  |
|  4 bits |    6 bits   |    6 bits   |

Example: ADD R1, R2

  • Opcode: ADD (operation = addition)
  • Operand 1: R1 (destination register)
  • Operand 2: R2 (source register)
  • Meaning: Add the value in R2 to R1 and store result in R1

Binary Representation Example:

Instruction: ADD R1, R2
Binary:  0001  000001  000010
          |      |        |
        OPCODE  R1       R2
        (ADD=0001)

Types of Instruction Sets:

  • RISC (Reduced Instruction Set Computer): Small, simple instruction set. Faster execution. Used in ARM processors (smartphones).
  • CISC (Complex Instruction Set Computer): Large set of complex instructions. Used in Intel x86 processors.
Why is a bus used in a computer? How does a Control Bus differ from a Data Bus?
▼

What is a Bus?

A bus is a communication system (set of wires/traces) that transfers data between components of a computer such as the CPU, memory, and I/O devices. It acts as a shared pathway (highway) for signals.

Why Buses are Used:

  • Reduces the number of wires needed (multiple devices share one bus)
  • Standardizes communication between components
  • Allows easy expansion and connection of new devices
  • Cost-effective compared to direct point-to-point connections

Types of Buses:

1. Data Bus

  • Carries the actual data being processed or transferred
  • Bidirectional – data can flow in both directions (to and from CPU)
  • Width (8-bit, 16-bit, 32-bit, 64-bit) determines how much data is transferred at once
  • Example: CPU reads data from RAM, or sends data to printer

2. Address Bus

  • Carries memory addresses to specify where data should be read from or written to
  • Unidirectional – only CPU sends addresses (one way)
  • Width determines how much memory can be addressed (32-bit = 4 GB max)

3. Control Bus

  • Carries control signals (commands) from the CPU to coordinate operations
  • Bidirectional – some signals go to devices, some come back (interrupt signals)
  • Carries signals like: Read, Write, Clock, Reset, Interrupt, Enable
  • Tells devices whether an operation is a read or write
Feature Data Bus Control Bus
Purpose Transfers actual data Transfers control signals/commands
Direction Bidirectional Bidirectional (mostly from CPU)
Content Numbers, characters, instructions Read/Write, Clock, Reset signals
Width 8, 16, 32, or 64 bits Varies (4–10 control lines)
Explain the working mechanism of a keyboard.
▼

Keyboard Definition:

A keyboard is the primary input device of a computer. It consists of an array of keys (letters, numbers, function keys, special keys) that allow users to enter text and commands.

Working Mechanism of a Keyboard:

Step 1: Key Press

  • When you press a key, it pushes down a switch beneath it
  • The switch connects two electrical contacts (completing a circuit)
  • Modern keyboards use membrane switches, mechanical switches, or capacitive switches

Step 2: Key Matrix Scanning

  • Keys are arranged in a grid called a key matrix (rows and columns of wires)
  • A microcontroller (keyboard processor) continuously scans this matrix hundreds of times per second
  • When a key is pressed, it creates a unique row-column intersection signal

Step 3: Keycode Generation

  • The keyboard's microcontroller identifies which key was pressed from the matrix position
  • It generates a unique scan code (a number identifying the key)
  • Both "key pressed" (make code) and "key released" (break code) signals are sent

Step 4: Signal Transmission

  • The scan code is sent to the computer via interface (USB, PS/2, Bluetooth, or wireless)
  • For USB keyboards, data is sent as USB HID (Human Interface Device) packets

Step 5: OS Processing

  • The operating system's keyboard driver receives the scan code
  • It converts the scan code into a character code (ASCII or Unicode)
  • The character is sent to the active application (e.g., text editor displays the letter)

Summary Flow:

Key Pressed → Switch Closed → Matrix Scanned → Scan Code Generated → Sent via USB/Wireless → OS Driver Converts to Character → Application Displays Output

Explain the working mechanism of a mobile phone.
▼

Mobile Phone Overview:

A mobile phone is a portable wireless communication device. Modern smartphones are essentially pocket-sized computers with communication capabilities. They combine hardware and software to perform voice calls, data communication, and computing tasks.

Key Hardware Components:

  • Processor (SoC): System on Chip — the "brain" of the phone (e.g., Qualcomm Snapdragon, Apple A-series). Contains CPU, GPU, modem, and more on one chip.
  • RAM: Temporary memory for running apps
  • Internal Storage (Flash): Stores OS, apps, photos, and files
  • Battery: Lithium-ion or lithium-polymer battery provides power
  • Display: Touchscreen (LCD or OLED) for output and input
  • Camera: Image sensors for photos/videos
  • Sensors: Accelerometer, gyroscope, proximity sensor, fingerprint scanner

Working Mechanism – Communication:

1. Cellular Network Communication

  • Mobile phone contains a transceiver (transmitter + receiver)
  • It communicates with the nearest Base Station (cell tower) using radio waves (electromagnetic waves)
  • The country is divided into geographic areas called cells, each served by a tower
  • When you make a call: Phone → Cell Tower → Mobile Switching Center (MSC) → Another Phone

2. SIM Card Role

  • SIM (Subscriber Identity Module) stores your identity and network credentials
  • Authenticates you to the network and stores your phone number/contacts

3. Voice Call Working

  • Microphone captures your voice (analog sound)
  • Analog signal is converted to digital (ADC)
  • Digital data is compressed, encoded, and transmitted via radio waves
  • Receiver decodes and converts back to analog (DAC) for the speaker

4. Internet / Data

  • Phone connects to internet via cellular data (3G/4G/5G) or Wi-Fi
  • Wi-Fi uses radio waves on 2.4 GHz or 5 GHz bands via router
  • Bluetooth enables short-range wireless connections (headphones, etc.)

5. Operating System

  • Mobile OS (Android, iOS) manages all hardware and runs applications
  • Apps communicate with hardware through APIs provided by the OS

A hard copy is a physical, tangible output of computer data printed on paper or another medium. It is a permanent output that can be read without a device.

Explain the OSI Reference Model in detail, describing the specific function of each of the seven layers.
▼

OSI (Open Systems Interconnection) Reference Model:

The OSI model is a 7-layer conceptual framework that describes how communication occurs between computers on a network. It was developed by the International Organization for Standardization (ISO).

Layer 1: Physical Layer

  • Function: Transmits raw binary data (bits) over physical medium
  • Deals with physical connections, cables, and signals
  • Defines mechanical and electrical specifications
  • Examples: Ethernet cables, fiber optic cables, hubs, repeaters
  • Data Unit: Bits

Layer 2: Data Link Layer

  • Function: Provides reliable data transfer between adjacent network nodes
  • Responsible for framing and error detection
  • Manages MAC addresses (physical addresses)
  • Examples: Switches, bridges, Network Interface Cards (NICs)
  • Protocols: Ethernet, PPP
  • Data Unit: Frames

Layer 3: Network Layer

  • Function: Routes data packets from source to destination
  • Handles IP addressing and logical routing
  • Manages congestion and quality of service
  • Examples: Routers, Layer 3 switches
  • Protocols: IP (IPv4, IPv6), ICMP, IGMP
  • Data Unit: Packets

Layer 4: Transport Layer

  • Function: Provides end-to-end communication and data delivery guarantees
  • Manages connections, flow control, and error recovery
  • Allows applications to communicate with each other
  • Protocols: TCP (connection-oriented), UDP (connectionless)
  • Data Unit: Segments (TCP) or Datagrams (UDP)

Layer 5: Session Layer

  • Function: Manages and maintains communication sessions
  • Establishes, maintains, and terminates connections
  • Handles session synchronization and checkpointing
  • Manages dialogue control (half-duplex, full-duplex)
  • Examples: Session establishment protocols, authentication

Layer 6: Presentation Layer

  • Function: Translates, encrypts, and compresses data
  • Ensures data is readable for the application
  • Handles character encoding and data format conversion
  • Examples: SSL/TLS encryption, JPEG, MPEG compression
  • Performs data translation and encryption/decryption

Layer 7: Application Layer

  • Function: Provides network services directly to end-user applications
  • Enables user access to network resources
  • Examples: Web browsers, email clients, file transfer applications
  • Protocols: HTTP, HTTPS, FTP, SMTP, POP3, IMAP, DNS, Telnet

What is a browser? How does a browser work? Explain.
▼

Browser Definition:

A web browser is a software application used to access, retrieve, and display content from the World Wide Web (WWW). It acts as a client that communicates with web servers to fetch web pages.

Examples: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, Opera.

How a Browser Works – Step by Step:

Step 1: URL Entry

  • User types a URL (Uniform Resource Locator) like https://www.google.com in the address bar
  • URL contains: Protocol (https), Domain name (www.google.com), Path (/search)

Step 2: DNS Resolution

  • Browser asks the DNS (Domain Name System) server to convert the domain name to an IP address
  • e.g., "www.google.com" is resolved to an IP like 142.250.80.36

Step 3: TCP Connection

  • Browser establishes a TCP connection with the web server at that IP address
  • For HTTPS, a secure SSL/TLS handshake is performed for encryption

Step 4: HTTP Request

  • Browser sends an HTTP/HTTPS GET request to the server asking for the web page

Step 5: Server Response

  • The web server processes the request and sends back the web page files (HTML, CSS, JavaScript, images)

Step 6: Rendering

  • The browser's rendering engine processes the received files
  • It builds the DOM (Document Object Model) from HTML
  • Applies CSS styles for visual layout
  • Executes JavaScript for interactivity
  • Finally displays the webpage visually to the user

Key Components of a Browser:

  • User Interface: Address bar, back/forward buttons, bookmarks
  • Rendering Engine: Displays HTML/CSS content (e.g., Blink in Chrome)
  • JavaScript Engine: Executes JS code (e.g., V8 in Chrome)
  • Network Layer: Handles HTTP/HTTPS requests
  • Data Storage: Cookies, cache, local storage

Protocol Definition:

A network protocol is a set of rules and standards that govern how data is formatted, transmitted, received, and acknowledged between devices on a network. Protocols ensure different devices can communicate correctly.

Common Network Protocols:

A Personal Area Network (PAN) is the smallest type of network, designed for communication between devices of a single person within a very short range (typically within 10 meters or less).

Characteristics of PAN:

  • Very short range (1-10 meters)
  • Designed for personal/individual use
  • Low power consumption
  • Connects personal devices like phone, laptop, headphones, smartwatch

Types of PAN:

Examples of PAN Usage:

Define IP address. Why do we need it? Compare IPv4 and IPv6 addresses.
▼

IP Address Definition:

An IP (Internet Protocol) address is a unique numerical label assigned to each device connected to a network. It serves as the device's identity on the internet or local network, allowing data to be sent and received correctly.

Why We Need an IP Address:

  • Identification: Uniquely identifies each device on a network
  • Location Addressing: Helps route data packets to the correct destination
  • Communication: Without an IP, devices cannot send or receive data over a network
  • Just like a postal address for physical mail, IP addresses ensure data reaches the right device

IPv4 (Internet Protocol version 4):

  • 32-bit address (4 bytes)
  • Written as 4 decimal numbers separated by dots: 192.168.1.1
  • Each number ranges from 0-255
  • Supports approximately 4.3 billion unique addresses
  • Running out of addresses due to internet growth

IPv6 (Internet Protocol version 6):

  • 128-bit address (16 bytes)
  • Written as 8 groups of 4 hexadecimal digits separated by colons
  • Example: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
  • Supports approximately 3.4 x 10^38 unique addresses (virtually unlimited)
  • Better security (IPSec built-in), faster routing, no need for NAT

Define an Operating System. Explain its primary functions: Process Management, Memory Management, and File Management.
▼

Operating System Definition:

An Operating System (OS) is a system software that acts as an intermediary between the user and the computer hardware. It manages all hardware resources and provides services and an environment for users to run applications efficiently.

Primary Functions of Operating System:

1. Process Management

  • Definition: Creating, scheduling, and managing execution of processes (running programs)
  • Process Creation: OS creates new processes when applications are launched
  • Process Scheduling: Decides which process gets CPU time and for how long using scheduling algorithms (FIFO, Round Robin, Priority-based)
  • Context Switching: OS switches between processes to run multiple programs simultaneously
  • Process Synchronization: Ensures processes don't interfere with each other
  • Process Termination: OS safely terminates processes and frees resources

2. Memory Management

  • Definition: Managing the computer's memory (RAM) efficiently
  • Memory Allocation: Allocates memory space to processes when they start
  • Virtual Memory: Uses disk space as extension of RAM for processes larger than physical memory
  • Paging: Divides memory into fixed-size pages and moves them between RAM and disk
  • Segmentation: Divides memory into segments of different sizes
  • Memory Deallocation: Frees memory when processes terminate
  • Garbage Collection: Reclaims unused memory automatically

3. File Management

  • Definition: Manages file storage, organization, and access on secondary memory
  • File Creation/Deletion: OS allows creation and deletion of files
  • File Organization: Organizes files in directory/folder structure
  • File Access Control: Manages file permissions (read, write, execute)
  • File Storage: Determines where files are stored on disk
  • File Protection: Protects files from unauthorized access
  • File Backup: Manages file backup and recovery

Additional OS Functions:

  • I/O Management: Controls input/output devices (printer, keyboard, etc.)
  • User Interface: Provides GUI or CLI for user interaction
  • Security: Protects system from unauthorized access
  • Networking: Manages network connections

Define Data Redundancy and Data Integrity in the context of a database.
▼

Data Redundancy:

Definition: Duplication of data where the same information is stored in multiple places within the database.

Types of Data Redundancy:

  • Intentional Redundancy: Deliberately duplicated for backup and recovery purposes
  • Unintentional Redundancy: Unwanted duplication that causes problems

Problems Caused by Redundancy:

  • Data Inconsistency: When redundant data is updated in one place but not another
  • Update Anomaly: Difficulty in updating all copies consistently
  • Storage Waste: Unnecessary consumption of disk space
  • Maintenance Complexity: More difficult to maintain data accuracy

Example of Data Redundancy:

A student's phone number stored in both Student table and Enrollment table. If the number changes, it must be updated in both places.

Data Integrity:

Definition: Accuracy, completeness, and consistency of data in the database throughout its lifecycle.

Types of Data Integrity:

1. Entity Integrity:

  • Every table must have a primary key
  • Primary key values must be unique and non-null
  • Ensures each record is uniquely identifiable

2. Referential Integrity:

  • Foreign key values must exist in the referenced table
  • Maintains relationships between tables
  • Example: Student ID in Enrollment must exist in Student table

3. Domain Integrity:

  • Data values must conform to defined types and ranges
  • Example: Age must be between 0-150, Email must be in valid format

4. User-defined Integrity:

  • Custom rules defined by users or business logic
  • Example: Salary must be positive, GPA between 0-4

Maintaining Data Integrity:

  • Use constraints (NOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY)
  • Data validation at input
  • Regular audits and checks
  • Proper backup and recovery procedures
  • Access control and authentication

Integrity Constraints Example:

CREATE TABLE Student (
    StudentID INT PRIMARY KEY,              -- Entity Integrity
    StudentName VARCHAR(100) NOT NULL,     -- Domain Integrity
    Age INT CHECK (Age >= 18),             -- Domain Integrity
    Email VARCHAR(100) UNIQUE,             -- Domain Integrity
    DepartmentID INT FOREIGN KEY           -- Referential Integrity
);

Database Definition:

A database is an organized collection of structured data stored electronically in a computer system. A database is managed by a Database Management System (DBMS) which provides tools to store, retrieve, update, and manage data efficiently.

Relational Model:

The relational model was proposed by E.F. Codd in 1970. It is the most widely used database model. Data is organized into tables (called relations), where each table represents a real-world entity and its attributes.

Key Concepts of the Relational Model:

1. Table (Relation)

  • Data is stored in a 2D structure with rows and columns
  • Each table represents one entity (e.g., Student, Employee)

2. Row (Tuple/Record)

  • Each row represents one instance/record of the entity
  • E.g., one student's complete information

3. Column (Attribute/Field)

  • Each column represents a property/attribute of the entity
  • E.g., StudentID, Name, Age, Grade

4. Primary Key

  • A unique identifier for each row in a table
  • Cannot be NULL or duplicate
  • Example: StudentID is the primary key in the Student table

5. Foreign Key

  • A column that refers to the primary key of another table
  • Used to establish relationships between tables
  • Example: EnrollmentID in Course table references StudentID in Student table

How does a Firewall protect a network from unauthorized access?

Firewall Definition:

A Firewall is a network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules. It acts as a barrier between trusted networks and untrusted networks (like the internet).

How Firewalls Protect Networks:

1. Packet Filtering

  • Examines each data packet (unit of transmitted data)
  • Checks source IP, destination IP, port numbers, and protocol
  • Allows or blocks packets based on rules
  • Example: Block traffic from suspicious IP addresses

2. Stateful Inspection

  • Tracks active connections
  • Remembers state of connections
  • Allows return traffic only for established connections
  • More sophisticated than simple packet filtering

3. Proxy Service

  • Acts as intermediary between users and external servers
  • Hides internal IP addresses from outside world
  • Analyzes requests before forwarding
  • Can cache content for faster access

4. Intrusion Detection and Prevention

  • Monitors for suspicious patterns and activities
  • Detects known attack signatures
  • Can block or alert on malicious traffic

Key Protection Mechanisms:

  • Port Management: Blocks unused ports, only allows specific ports (e.g., 80 for HTTP, 443 for HTTPS)
  • Protocol Filtering: Allows only necessary protocols (TCP, UDP, ICMP)
  • IP Filtering: Blocks traffic from blacklisted IP addresses
  • DDoS Protection: Prevents Distributed Denial of Service attacks
  • VPN Support: Creates encrypted secure tunnels for remote access

Types of Firewalls:

  • Hardware Firewall: Physical device between network and internet (e.g., router firewall)
  • Software Firewall: Installed on individual computers (e.g., Windows Defender Firewall)
  • Hybrid: Combination of hardware and software firewalls

What Firewalls CAN Do:

  • ✓ Block unauthorized traffic
  • ✓ Prevent unauthorized external access
  • ✓ Hide internal network details
  • ✓ Log and monitor traffic
  • ✓ Enforce security policies

What Firewalls CANNOT Do:

  • ✗ Protect against viruses in already-allowed traffic
  • ✗ Prevent authorized users from misusing access
  • ✗ Encrypt data passing through
  • ✗ Protect against all advanced threats

Big Data refers to extremely large and complex datasets that are too massive or complex for traditional data processing applications to handle efficiently. It requires specialized tools and technologies to store, process, and analyze.

What is cryptography? How does cryptography provide security to our data?
▼

Cryptography Definition:

Cryptography is the science and practice of securing information by transforming it into an unreadable format so that only authorized parties can read it. The word comes from Greek: "kryptos" (hidden) + "graphein" (writing).

Key Terms:

  • Plaintext: The original readable data/message
  • Ciphertext: The encrypted, unreadable version of data
  • Encryption: The process of converting plaintext to ciphertext using a key
  • Decryption: The process of converting ciphertext back to plaintext using a key
  • Key: A secret value used in encryption/decryption algorithms

How Cryptography Provides Security:

1. Confidentiality

  • Encrypts data so only the intended recipient can read it
  • Even if data is intercepted, it appears as meaningless ciphertext
  • Example: HTTPS encrypts all web data you send/receive

2. Integrity

  • Uses cryptographic hash functions (MD5, SHA-256) to verify data has not been tampered with
  • Any change in the data changes the hash value, detecting modification

3. Authentication

  • Digital signatures verify the identity of the sender
  • Ensures the message actually came from who it claims to be from

4. Non-repudiation

  • The sender cannot deny sending a message (proven by digital signature)

Types of Cryptography:

  • Symmetric Encryption: Same key for encryption and decryption. Fast but key distribution is a problem. Example: AES (Advanced Encryption Standard).
  • Asymmetric Encryption (Public Key): Two keys — public key (encrypt) and private key (decrypt). Slower but more secure. Example: RSA, used in HTTPS/SSL.
  • Hash Functions: One-way transformation. Cannot be reversed. Used for password storage. Example: SHA-256, MD5.

Real-World Applications:

  • HTTPS/SSL: Secures web browsing
  • Banking: Secures online transactions
  • Messaging: End-to-end encryption (WhatsApp)
  • Password storage: Hashed passwords in databases
  • Digital certificates: Verifying website identity
