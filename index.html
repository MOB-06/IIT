10 Marks Long Answer Questions
Explain the five generations of computers based on their key switching components, with examples.
▼

Five Generations of Computers:

1st Generation (1946-1956) - Vacuum Tubes

  • Switching Device: Vacuum Tubes
  • Size: Room-sized, very large
  • Speed: Slow (milliseconds)
  • Cost: Extremely expensive
  • Example: ENIAC, UNIVAC, Mark-I
  • Characteristics: Generated excessive heat, required cooling systems, high power consumption

2nd Generation (1956-1963) - Transistors

  • Switching Device: Transistors
  • Size: Cabinet-sized, smaller than vacuum tubes
  • Speed: Faster (microseconds)
  • Cost: Expensive but more affordable than generation 1
  • Example: IBM 7090, Honeywell 400
  • Characteristics: Less heat, lower power consumption, improved reliability

3rd Generation (1963-1971) - Integrated Circuits (ICs)

  • Switching Device: Integrated Circuits (Small Scale Integration)
  • Size: Desk-sized
  • Speed: Faster (nanoseconds)
  • Cost: Reduced cost
  • Example: IBM System/360, Honeywell 6000
  • Characteristics: Multiple transistors on single chip, parallel processing, introduction of operating systems

4th Generation (1971-1980) - Microprocessors

  • Switching Device: Microprocessors (Large Scale Integration - LSI, Very Large Scale Integration - VLSI)
  • Size: Personal Computer size
  • Speed: Much faster (picoseconds)
  • Cost: Affordable
  • Example: Apple II, IBM PC, Intel 4004, Intel 8085
  • Characteristics: Desktop computers, graphical user interfaces, networking capabilities

5th Generation (1980-Present) - AI and Advanced Processors

  • Switching Device: Ultra Large Scale Integration (ULSI), Quantum Computing
  • Size: Portable, smartphones, tablets, wearables
  • Speed: Extremely fast (femtoseconds)
  • Cost: Low cost, affordable
  • Example: Modern Intel/AMD processors, GPUs, AI chips
  • Characteristics: Artificial Intelligence, Quantum Computing, IoT, Cloud Computing, Mobile Computing
Define a computer system. Describe the internal functional units of a CPU (ALU, CU, and Registers).
▼

Definition of Computer System:

A computer system is an electronic device that accepts data as input, processes it using predefined instructions, and produces meaningful output. It consists of hardware and software working together to perform computational tasks.

Internal Functional Units of CPU:

1. Arithmetic Logic Unit (ALU)

  • Performs all arithmetic operations (addition, subtraction, multiplication, division)
  • Performs all logical operations (AND, OR, NOT, XOR)
  • Compares values and sets condition flags
  • Most critical unit for actual data processing

2. Control Unit (CU)

  • Directs and coordinates all operations of the computer
  • Fetches instructions from memory
  • Decodes instructions and determines what to do
  • Controls the flow of data and instructions
  • Sends control signals to other units
  • Manages timing and synchronization

3. Registers

  • Extremely fast temporary storage locations within the CPU
  • Store data currently being processed
  • Store addresses of memory locations
  • Store instruction being executed
  • Much faster than main memory (RAM)
  • Limited in quantity (typically 8-32 registers)
  • Types: Accumulator Register, Data Registers, Address Registers, Instruction Register, Program Counter

Capacity Limited (1-32 GB) Large (1 TB - 10 TB)

Primary Memory Details:

RAM (Random Access Memory): Temporary, volatile storage for active programs and data. Loses all content when powered off.

ROM (Read Only Memory): Permanent, non-volatile storage containing firmware. Cannot be easily modified.

Secondary Memory Details:

Permanent storage for long-term data retention. Examples: Hard Disk Drive (HDD), Solid State Drive (SSD), USB flash drives, SD cards.

What is Cache Memory? Explain why it is used despite its high cost.
▼

Cache Memory Definition:

Cache Memory is an extremely fast, small-sized memory that stores copies of frequently accessed data from main memory (RAM). It acts as a buffer between the CPU and RAM.

Characteristics of Cache:

  • Very fast access time (1-10 nanoseconds)
  • Small storage capacity (256 KB - 16 MB per level)
  • Located directly on the CPU die or nearby
  • Expensive (10-100 times more expensive than RAM)
  • Automatically managed by hardware

Levels of Cache:

L1 Cache: Smallest but fastest (8-64 KB per core)

L2 Cache: Larger and slightly slower (256 KB - 1 MB)

L3 Cache: Largest but slower (2-20 MB, shared among cores)

Why Cache is Used Despite High Cost:

  • Speed: Cache is 100-1000x faster than main memory
  • Performance: Significantly improves CPU performance by reducing memory access time
  • Temporal Locality: Recently accessed data is likely to be accessed again
  • Spatial Locality: Data near accessed location is likely to be needed soon
  • Bottleneck Reduction: Eliminates memory access bottleneck
  • Small Size: Small quantity needed (KB-MB range)
  • ROI: Performance gain justifies the cost

What are different types of Read Only Memory (ROM)? Explain Mask ROM, PROM, EPROM, and EEPROM.
▼

Read Only Memory (ROM):

ROM is non-volatile memory that permanently stores data/firmware. Its contents are retained even when power is off. It is used to store the BIOS/firmware that initializes the computer.

Types of ROM:

1. Mask ROM

  • The oldest type of ROM
  • Data is permanently written during the manufacturing process using a mask/template
  • Cannot be erased or reprogrammed after manufacture
  • Very cheap for large production runs
  • Used in: Game cartridges, calculator chips, embedded firmware

2. PROM (Programmable ROM)

  • Can be programmed once by the user after manufacture (using a PROM burner)
  • Once programmed, data cannot be changed or erased
  • Uses tiny fuses that are blown during programming
  • More flexible than Mask ROM for small production
  • Used in: Initial firmware loading, custom applications

3. EPROM (Erasable Programmable ROM)

  • Can be erased using ultraviolet (UV) light and reprogrammed
  • Has a transparent quartz window on top of the chip for UV exposure
  • Erasing takes 15–20 minutes under UV light
  • Can be reprogrammed multiple times
  • Used in: Development prototypes, older BIOS chips

4. EEPROM (Electrically Erasable Programmable ROM)

  • Can be erased and reprogrammed electrically (no UV light needed)
  • Can erase individual bytes instead of the whole chip
  • Much faster and more convenient than EPROM
  • Can be reprogrammed thousands of times
  • Used in: Modern BIOS/UEFI chips, smart cards, microcontrollers
  • Flash memory is a type of EEPROM widely used in USB drives, SSDs
Feature Mask ROM PROM EPROM EEPROM
Programmable No (factory only) Once Multiple (UV) Multiple (electrical)
Erasable No No Yes (UV light) Yes (electrically)
Cost Cheapest (bulk) Low Medium Highest
Flexibility None Low Medium High
What is an Instruction Set? Explain instruction format with example.
▼

Instruction Set:

An instruction set (also called Instruction Set Architecture or ISA) is the complete collection of all commands/instructions that a CPU can understand and execute. Different processors have different instruction sets (e.g., x86, ARM, MIPS).

Examples of Instructions:

  • ADD – Adds two values
  • MOV – Moves data from one location to another
  • LOAD – Loads data from memory to register
  • STORE – Stores data from register to memory
  • JMP – Jumps to a new instruction (branching)
  • SUB – Subtracts two values

Instruction Format:

An instruction format is the structure (layout) of a machine instruction. Every instruction typically contains:

  • Opcode (Operation Code): Specifies the operation to perform (e.g., ADD, MOV, LOAD). Typically 4–8 bits.
  • Operand(s): The data or address to operate on. Can be registers (R1, R2), memory addresses, or immediate values.

General Format:

| OPCODE  |  OPERAND 1  |  OPERAND 2  |
|  4 bits |    6 bits   |    6 bits   |

Example: ADD R1, R2

  • Opcode: ADD (operation = addition)
  • Operand 1: R1 (destination register)
  • Operand 2: R2 (source register)
  • Meaning: Add the value in R2 to R1 and store result in R1
